# ReelStyles

If `setup/setup.sh check` (Windows: `setup\setup.ps1 check`) has not passed on this machine, or the user says "set up ReelStyles", follow `skills/reelstyles-setup/SKILL.md` first.

When the user asks for a video, an animation, a Short/Reel/TikTok or a film in one of the ReelStyles styles, read `skills/reelstyles/SKILL.md` first and follow it step by step. It points to the styles (`STYLES.md`), the formats (`formats.json`) and the shared render steps (`RENDER.md`); each kit in `skills/reelstyles/kits/<id>/` has its own STYLE.md, RENDER.md and RUBRIC.md.
