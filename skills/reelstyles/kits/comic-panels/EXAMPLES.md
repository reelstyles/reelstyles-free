# Example prompts

1. Using only the kit in this folder, make a 20-second 16:9 comic-page film: a courier hero spots a robot on a rooftop, trades one line, and ends with a punch and BAM. Render it to out.mp4.
2. Using only the kit in this folder, make a 25-second 16:9 explainer as a comic page: "Why does bread go stale?" Panel 1 a loaf at midnight (caption), panel 2 a villain "Stale Air" balloon, panel 3 close-up of crumbs, panel 4 a sound-effect payoff, end on a "To be continued" page.
3. Using only the kit in this folder, make a 15-second product teaser as a comic page: three panels, each with one balloon and one star-burst word, camera pushing panel to panel, ending on a splash page with the product name in a caption box. Render it to out.mp4.
