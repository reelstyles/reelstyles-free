# Example prompts

1. Using only the kit in this folder, make a 20-second 16:9 launch film for a fictional note-taking app: open on the number, show clutter collapsing into one tile, end on the wordmark. Render to out.mp4 and run the hold check.
2. Using only the kit in this folder, make a 25-second 16:9 release-checklist countdown for a fictional deploy tool: each checklist item is one UI moment, ending on a single "shipped" toast. Render to out.mp4.
3. Using only the kit in this folder, make a 20-second 16:9 side-by-side film: an old manual workflow drowning on the left, the new one finishing early on the right, violet accent. Render to out.mp4.
