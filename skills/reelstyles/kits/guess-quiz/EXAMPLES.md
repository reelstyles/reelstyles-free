# Example prompts

1. Using only the kit in this folder, make a 26-second 16:9 quiz film: four bands (easy to impossible), one round each, with a banana, a cat, a pineapple and the Swiss flag. Render it to out.mp4 and run the freeze check.
2. Using only the kit in this folder, make a 9:16 Short from `templates/film-v.js` with seven rounds (4.6 s each, 1.0 s title cards): animals only. Add two new animals to `sets/items.js` (a rabbit, a whale). Render with `bash tools/render.sh`.
3. Using only the kit in this folder, make a 30-second "flags of the world" quiz: five waving flags (add Ireland, France, Poland), a longer 4 s ring in the hard bands (`T_RING`), score 5 / 5 at the end.
