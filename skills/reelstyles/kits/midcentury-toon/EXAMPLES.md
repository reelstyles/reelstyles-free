# Example prompts

1. Using only the kit in this folder, make a 35-second 16:9 set-up guide for a smart thermostat in 3 steps (mount, connect the app, set a schedule). Open on the finished result, one hand action per step, end on a tip banner held still. Render it to out.mp4.
2. Using only the kit in this folder, make a 30-second rules card for a public pool: four rules, one held figure and a numbered medallion per rule, each rule shown as a do / don't colour-block split. Render it to out.mp4.
3. Using only the kit in this folder, make a 40-second recipe card for pancakes: side view on a counter, a call-out on the hands for each quantity, and a top-view pattern as the payoff. Render it to out.mp4.

Vertical: for a 9:16 Short, say "make it a vertical 1080x1920 film" and start from `templates/vertical.html` and `templates/film-v.js` (see `STYLE.md`, Files); the prompts above work unchanged, with the shots re-staged for a tall frame.
