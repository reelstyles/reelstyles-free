# Example prompts

1. Using only the kit in this folder, make a 28-second 9:16 silent Short with six metaphors about why consistency beats intensity (hard way vs smart way, today / a month / a year, stairs vs slope, drop what weighs, find the door, domino). End on a reversal question and loop to frame one. Render it to out.mp4.
2. Using only the kit in this folder, make a 32-second 9:16 Short about focus: add two new metaphors by copying a move in `sets/metaphors.js` (a tug of war with a rope; two doors, only one yellow). Use red as the accent. Run the freeze check and fix every hit.
3. Using only the kit in this folder, make a 24-second 16:9 version about saving money: today / a month / a year as growing coin stacks, stairs vs slope, end on "WHAT IF YOU STARTED TODAY?".
